## About

This repository hosts the documentation page for [Kromo Tools](https://www.kromotools.net/), a free collection of 200+ online calculators, converters, PDF and image utilities, generators and AI-powered helpers. No account, no paywall, no clutter.

The guide answers the questions people ask before using a tool: what it does, whether it runs in the browser, what happens to the text you enter, what the limits are, and where to report a problem. It is a single static page, so it loads quickly and works on any device.

**Live guide:** https://kromotools.github.io/kromotools-guide/

If you add a new page, also add its address to `sitemap.xml`.

## FAQ

**Is this guide official?**
Yes. It is published by the Kromo Tools team. The tools themselves live at [kromotools.net](https://www.kromotools.net/).

**Are the tools really free?**
Yes. All tools are free, with no subscription and no account.

**Do the tools store what I enter?**
The website says it does not store tool inputs. Most tools run in your browser. AI tools pass your text to an AI provider to produce a result.

**How accurate are the results?**
Formulas come from published sources and are tested against manual calculations, but results are estimates. Double-check anything important.

**Can I request a new tool?**
Yes, through [Request a Tool](https://www.kromotools.net/p/request-tool.html).

## Keeping It Accurate

Tool names, prices and policies can change on the main website, so the website is always the final reference. Each tool is re-checked at least every 90 days. If something in this guide looks out of date, use [General Feedback](https://www.kromotools.net/p/general-feedback.html) or [Contact Us](https://www.kromotools.net/p/contact-us.html).

Read more in the [Editorial Policy](https://www.kromotools.net/p/editorial-policy.html) and [Team and Research Process](https://www.kromotools.net/p/team-research-process.html).
